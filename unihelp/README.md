# unihelp-website

يوني هيلب - منصة متكاملة لخدمات الطلاب الجامعيين

A comprehensive platform offering professional presentation services, web and mobile applications, and complete project documentation for university students.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

## Features

- Professional presentation design and creation
- Web and mobile application development
- Complete project documentation
- Dark and light theme support (automatic detection based on system preferences)
- Bilingual support (Arabic and English)
- RTL/LTR layout switching
- Integrated contact form with WhatsApp integration
